# ModeCalc v1.2.0

音阶库重构版本：去掉父-子音阶，改为独立音阶行 + 分类折叠 + 信息列。

![ModeCalc v1.2.0](https://raw.githubusercontent.com/lewihuang/ModeCalc/main/docs/images/modecalc.png)

## 下载

- `ModeCalc-v1.2.0-win64.zip`：免安装，解压后运行 `ModeCalc.exe`
- `ModeCalc.exe`：单文件版（与 zip 内为同一构建）

## 主要变化

- **独立音阶行**：每个调式可单独启用/停用；分组头支持三态全选，分类可折叠。
- **默认 71 个音阶**：
  - Natural Mode（7）
  - Harmonic Major / Harmonic Minor / Melodic Minor（各 7）
  - Jazz（Blues 1/2、Bebop ×3，共 5）
  - Modes of limited transposition（全音阶、减音阶 ×2、Messiaen 3–7、增音阶 ×2，共 10）
  - World Music（Chinese 8、Japanese 4、Gypsy 1、Flamenco 1、Hungarian 2、Neapolitan 2、Indian 5、Arabic 5，共 28）
- **Chinese 五声 + 七声**：Gong/Shang/Jue/Zhi/Yu 与 Yayue/Qingyue/Yanyue。
- **信息列**：显示绝对等价示例（如 `C Ionian ≡ A Aeolian`）与别名；跨分类重复音列保留为默认关闭的别名行。
- **默认音阶只读**：改名/改音集会新建 Custom 副本，原默认行保留并关闭；默认行不可删除。
- **Custom 分类**与 World Music 同级，始终显示，即使为空。
- **设置按钮只在 Mode 显示**。
- **布局调整**：Matches 缩窄，右侧调式/设置面板加宽。

## 安装与运行

1. 下载并解压 `ModeCalc-v1.2.0-win64.zip`；
2. 双击 `ModeCalc.exe`；
3. 如遇 Windows SmartScreen 提示，选择“更多信息 → 仍要运行”（exe 未做代码签名）；
4. 需要 WebView2 Runtime：Windows 11 自带，Windows 10 可从微软官网安装；
5. 连接 MIDI 键盘后，在菜单栏 `MIDI Input` 选择设备。

## 已知限制

- exe 未做代码签名，首次运行可能触发 SmartScreen；
- 桌面版仅支持 Windows（pywebview + WebView2）；
- 世界音乐按文化名称单行，不展开完整 7 转位家族；
- 拖拽排序与自定义分类留待后续版本。
