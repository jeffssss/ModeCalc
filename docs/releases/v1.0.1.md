# ModeCalc v1.0.1

首个公开发布版本（Windows 桌面端）。

![ModeCalc v1.0.1](https://raw.githubusercontent.com/lewihuang/ModeCalc/main/docs/images/modecalc.png)

## 下载

- `ModeCalc-v1.0.1-win64.zip`：免安装，解压后运行 `ModeCalc.exe`
- `ModeCalc.exe`：单文件版（与 zip 内为同一构建）

## 功能

- MIDI 实时和弦识别：约 60 个和弦模板，支持转位与不完整匹配提示
- 调式识别：约 25 个父音阶，覆盖七声调式、有限移位调式、五声 & Blues、Bebop、世界民族调式
- Messiaen 有限移位调式以最小循环音程单元命名（如 `Messiaen 211`）
- 固定调式：音阶外按下音在键盘上以红色标记
- 派生调式：以固定调中心为锚，列出包含当前全部按下音的调式
- 五线谱、88 键钢琴、吉他指板可视化
- 15 个调号、MIDI 设备选择、延音踏板、母音阶勾选记忆

## 安装与运行

1. 下载并解压 `ModeCalc-v1.0.1-win64.zip`；
2. 双击 `ModeCalc.exe`；
3. 如遇 Windows SmartScreen 提示，选择“更多信息 → 仍要运行”（exe 未做代码签名）；
4. 需要 WebView2 Runtime：Windows 11 自带，Windows 10 可从微软官网安装；
5. 连接 MIDI 键盘后，在菜单栏 `MIDI Input` 选择设备。

## 已知限制

- exe 未做代码签名，首次运行可能触发 SmartScreen；
- 桌面版仅支持 Windows（pywebview + WebView2）；
- 没有 MIDI 输入设备时界面可打开，但不会产生识别结果。
