# ModeCalc v1.2.1

补丁版本：修复同音集音阶只显示第一条的问题。

## 修复

- 同时按下 C D E F G A B 且已启用 Chinese 组时，Matches 现在同时显示 **C Ionian** 和 **C Qingyue**，不再按音集去重。
- 所有已启用且命中的音阶行都会显示；默认库仍只启用 Natural Mode，因此不启用别名时行为不变。

## 下载

- `ModeCalc-v1.2.1-win64.zip`：免安装，解压后运行 `ModeCalc.exe`
- `ModeCalc.exe`：单文件版（与 zip 内为同一构建）

## 安装与运行

1. 下载并解压 `ModeCalc-v1.2.1-win64.zip`；
2. 双击 `ModeCalc.exe`；
3. 如遇 Windows SmartScreen 提示，选择“更多信息 → 仍要运行”（exe 未做代码签名）；
4. 需要 WebView2 Runtime：Windows 11 自带，Windows 10 可从微软官网安装；
5. 连接 MIDI 键盘后，在菜单栏 `MIDI Input` 选择设备。
