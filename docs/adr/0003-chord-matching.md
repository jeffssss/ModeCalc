# 和弦匹配策略：精确 → 子集 → 超集三级匹配

给定去重后的 pitch class set，按优先级匹配：

1. **精确匹配**：集合完全等于某和弦模板（允许转位）→ 直接返回
2. **子集匹配**：输入是某和弦的子集（如单缺三音）→ 返回该和弦，标记 `is_incomplete`
3. **超集匹配**：输入包含某和弦全部音 + 额外音，仅容忍八度/五度重复，其余 → N/A
4. **多候选消歧**：Phase 1 默认选根音最低的拼写（Phase 2 用户选调后按调号消歧）

**为何不坚持严格精确匹配？** MIDI 键盘演奏者常常按重复的根音或五音（多八度），严格匹配会把这些常见指法识别为 N/A，体验差。容忍八度/五度重复是最小必要灵活度。

**为何缺三音不算和弦？** 缺三音（如 C-G）的大三度暗示不足，更应识别为音程（纯五度）。同理缺三音的七和弦也不匹配。

**≥5 个不同 pitch class 为何直接 N/A？** Phase 1 只做三/七和弦。九和弦、十一和弦等延伸音+省略音的组合可能性爆炸，在没有调性上下文的情况下歧义太多。后续 Phase 扩展。
