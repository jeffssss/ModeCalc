# 2026-10-24 记住母音阶勾选状态

## 变更
- 新增 `settings_store.py`：设置读写（`%APPDATA%\ModeCalc\settings.json`，可用 `MODECALC_SETTINGS_DIR` 覆盖目录）；临时文件 + `os.replace` 原子写入，文件缺失/损坏/类型非法时安全回退。
- `app.py`
  - `MidiState.__init__` 启动时读取上次勾选，并过滤掉已不存在的音阶 id
  - `set_analysis_mode()` 在勾选变化时保存（未知 id 过滤后再写）
  - 新增 `Api.get_settings()` 供前端读取
  - 空勾选列表现在表示“一个都不启用”；此前 `[]` 会被 `if parents` 当作“全部启用”
- `static/app.js`
  - 勾选变化时无论 Chord / Mode 模式都同步到后端并落盘（此前仅在 Mode 模式发送）
  - 启动时调用 `get_settings()` 恢复复选框，并刷新各分组的三态
  - 删除 `bindAnalysisControls` 里与 `initGroupControls` 重复的 checkbox 监听
- `static/index.html`：帮助弹窗补充“勾选自动保存”说明
- 新增 `tests/test_settings_store.py`（8 个用例：往返、空列表、保留其他字段、损坏 JSON、类型非法、自动建目录、路径覆盖）

## 原因
勾选状态此前只存在 DOM 中，每次启动都回到 `index.html` 的默认值（10 个七声调式全选），用户每次都要重新调整。

## 影响
- 首次启动（无设置文件）仍沿用现有默认；之后重启恢复上次勾选。
- 桌面版（pywebview）生效；浏览器调试模式（`server.py` + WebSocket）暂未接入持久化。
- 设置文件与具体安装位置无关，换 exe 位置不影响记忆。
