# 2026-07-11 Match 点击 → 钢琴键盘高亮音阶

## 变更
- `mode_engine.py`
  - `detect_modes()`: 输出增加 `pcs` 字段（sorted int list 0-11）
- `static/keyboard.js`
  - `highlightKeys(activeMidi, scaleMidi)`: 双状态高亮，active 亮蓝优先于 scale 暗蓝
- `static/style.css`
  - 新增 `.key-white.scale`, `.key-black.scale`（暗蓝）
  - match 列表 hover/selected 样式（左蓝边 + 高亮背景）
- `static/app.js`
  - 新增 `selectedMatchPcs` 状态变量
  - `renderMatches()`: 挂 `data-pcs` + click handler
  - `onMatchClick()`: toggle 选中逻辑
  - `refreshSelectionHighlight()`: data-pcs 匹配恢复高亮
  - `updateUI()`: 键盘调用双参数（active + scale MIDI）
  - `sendAnalysisMode()`: 切换模式时清除选中

## 原因
用户需要在 matches 列表中点击一个调式，钢琴键盘高亮该音阶所有音符辅助创作。

## 影响
- 选中锁定：音符变化不取消选中
- 清除条件：toggle / 切模式 / 选另一个
- chord 模式 match 无 pcs → 点击忽略
