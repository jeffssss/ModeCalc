# 2026-10-24 固定音阶的红音标记与派生音阶

## 变更
- `static/keyboard.js`：`highlightKeys()` 新增 `active-out` 状态——固定音阶时，按下的音若在音阶外，用红色标记；在音阶内仍用原来的蓝色；未固定音阶时所有按下音仍是蓝色。
- `static/style.css`
  - `.key-white.active-out` / `.key-black.active-out`：填充 `#FF5768`（用户指定）
  - `#matches-list li.derived`：派生项的红色左边框与文字色
- `mode_engine.py`：`detect_modes()` 新增 `tonic_pc` 参数，可强制调中心（不传时仍取最低音）。
- `chord_engine.py`
  - `analyze()` 新增 `pinned_pcs` / `pinned_tonic` 参数，结果新增 `derived_matches`
  - 新增 `_derived_matches()`：Mode 模式、已固定音阶、≥2 个不同音高、且至少 1 个音在固定音阶外时，以固定调中心为锚点找包含全部按下音的音阶；排除固定音阶本身，返回全部候选
- `static/app.js`
  - `sendPinnedScale()`：固定/取消固定时把 `pcs + tonic_pc` 同步给后端（桌面走 pywebview API，浏览器调试走 WebSocket）
  - `renderMatches()`：派生项以 `↳ ` 前缀显示在固定项正下方，可点击切换固定；固定/派生/普通匹配按名称去重
  - 切回 Chord 模式时清除固定并通知后端
- `app.py` / `server.py`：保存 pinned 状态并传给 `analyze()`，桌面版与浏览器调试模式行为一致
- `static/index.html`：帮助弹窗补充红音与派生音阶说明
- 新增 `tests/test_derived_scale.py`（8 个用例）

## 原因
固定音阶后，按下音阶外音与音阶内音在键盘上是同一种蓝色，无法一眼看出“这个音不在当前音阶里”；同时缺少“这些音合起来属于哪个音阶”的提示。

## 影响
- 仅 Mode 分析模式且已点击固定某个 match 时生效。
- 派生项随按键实时变化；红音全部松开后自动消失；固定音阶本身不会出现在派生列表里。
- 派生范围 = 左侧当前勾选的母音阶；调中心固定为所固定音阶的调中心。
