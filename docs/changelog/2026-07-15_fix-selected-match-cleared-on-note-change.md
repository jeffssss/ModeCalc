# 2026-07-15 修复 selectedMatch 在松键/换音后被错误清除

## 变更
- `static/app.js`
  - `updateUI()`: 删除验证 `selectedMatch` 是否在 `_lastModeMatches` 中的自动清除逻辑（lines 215-219）

## 原因
上一个修复（2026-07-14）新增的验证本意是母音阶切换时清除无效选中，但引入了副作用：
- 松键后 `mode_matches=[]` 触发误清除
- 换不同音符后选中调式不在匹配集中也触发误清除

`selectedMatch` 是用户主动钉选的调式，语义为"高亮参考"，不应被后端数据自动覆盖。清除只能由用户显式操作触发：再次点击取消 / 切 Chord 模式。

## 影响
- Mode 分析模式下 match 选中/钉选交互
- 键盘高亮状态
