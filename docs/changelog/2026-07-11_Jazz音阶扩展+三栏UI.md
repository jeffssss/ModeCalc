# 2026-07-11 Jazz 音阶扩展 + 三栏 UI

## 变更
- `mode_engine.py`
  - 替换旧 `PARENT_SCALES` / `MODE_NAMES` 为统一的 `SCALE_REGISTRY`（20 条目，10 七音阶 + 4 对称 + 3 五声/Blues + 3 Bebop）
  - 新增 `_distinct_rotations()` 自动计算变长音阶的有效转位数
  - 重构 `detect_modes()`：支持 5~8 音音阶通用匹配、去重（`frozenset(pcs), tonic`）、三级排序（missing → category_priority → parent）
  - `format_mode_display()` 统一格式 `{tonic} {mode_name} ({scale_id} #{rotation+1})`
  - 保留 `PARENT_SCALES` / `MODE_NAMES` / `ALL_PARENTS` 向后兼容导出
- `static/index.html`
  - `#parent-checks` 从 3 个 flat 复选框改为 4 组分类折叠（七音阶/对称/五声&Blues/Bebop）
- `static/style.css`
  - 新增 `.scale-group` / `.group-header` / `.group-body` / `.group-toggle` 样式
  - 折叠/展开动画（旋转箭头）
- `static/app.js`
  - 新增 `initGroupControls()`：group checkbox 全选/partial、折叠切换
  - `getSelectedParents()` selector 改为 `.scale-check`
- `tests/test_mode_engine.py`：新增 17 个测试（七音阶扩展 5、对称 4、五声/Blues 4、Bebop 2、排序 2）

## 原因
调式功能从 3 母音阶 × 7 转位 = 21 调式扩展到 20 音阶注册条目，覆盖全部 jazz 即兴常用音阶体系。

## 影响
- 80 测试全绿（32 chord + 17 midi + 31 mode）
- UI 控制面板从 3 行变 4 分类折叠组，默认仅 Ionian/Melodic Minor/Harmonic Minor 勾选
- `chord_engine.py`、`app.py`、`server.py` 零改动
